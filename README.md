<br>
<sub> docs: https://aistudio.google.com/docs</sub>

# Setup
<h3>Discord Token</h2>
<br>
<h4>Get your bot token from the Developer Portal</h4>
<br>
<sub>link: https://discord.com/developers/home</sub> <br>
<h4>In config.json paste the token at <b>discord_token</b></h4>
<br>
<h3>Gemini Api Key</h2>
<br>
<h4>Go to the api key section in the aistudio</h4>
<br>
<sub>link: https://aistudio.google.com/api-keys</sub>
<br>
<h4>Press <b>Create API Key</b> (or use an existing one)</h4>
<br>
<h3>Changing the system prompt</h2>
<br>
<h4>To change the system prompt go to config.json and change the <b>system_prompt</b> feild</h4>
<br>
<h3>Add a Discord ChannelID</h2>
<br>
<h4>Go to the channel and right click, press <b>Copy Channel ID</b>, then go to config.json and paste it in the <b>channel_id</b></h4>
